# AMap Map Agent Skills

Agent Skills for AMap Map — geocoding, routing, places, migration guides and more.

高德地图 Agent Skills 合集，持续更新中。

⭐ If this project helps you, give it a star — it helps more developers find these skills.
如果对你有帮助，点个 Star 让更多开发者发现这个项目。

## Quick Install / 快速安装

```bash
npx skills add AMap-Web/amap-map-agent-skills
```

Supports 20+ AI clients: Cursor, Claude Desktop, Copilot, Codex, Windsurf, etc.

支持 20+ AI 客户端一键安装。
